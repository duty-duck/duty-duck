Monitor the successful execution of your critical recurring and individual tasks.
::

The Tasks feature of Duty Duck allows you to monitor the successful execution of your critical processes, such as your data backups, and react quickly in case of delay or failure.

This feature enables you to monitor the successful execution of an individual task or a recurring task (Cron Job). We can detect various failure scenarios for you, such as:
- An expected task started late
- An expected task was not executed at all
- A task failed and stopped
- A task did not stop as expected

![Tasks](/docs/images/task-details-page-en-1.png){height="300px"}

This monitoring is essential for several reasons:

1. **Operational Continuity**: Backups and other automated tasks are crucial for the continuity of your business. A missed backup can result in irreversible data loss.

2. **Early Problem Detection**: Monitoring allows you to quickly identify execution failures and intervene before a minor issue becomes critical. For example, the feature can be used to regularly monitor the available disk space on your servers and alert you in case of a problem.

3. **Compliance and Audit**: In many sectors, it is necessary to prove that backups are performed regularly for regulatory compliance reasons.

4. **Resource Optimization**: Monitoring ensures that tasks are executed within the expected timeframes and do not conflict with other processes. An alert can be sent to your team if a task starts late or takes longer than expected to execute.

### Use Cases

- Monitoring the successful execution of your database backups
- Regularly checking the available disk space on your servers
- Ensuring the successful execution of a task that generates and sends your clients' invoices once a month

### Quick Start

The easiest way to run a task is to use our [command-line tool](/en/docs/intro/cli-tool). This tool allows you to run any command and capture its execution duration, final status, and execution logs (from standard output). To do this, simply prefix the command you want to monitor with `dutyduck tasks run --task-id <task name>`. For example, if you have a backup script for a database called `database-backup.sh`, you can start monitoring its status by replacing the command with

```shell
dutyduck tasks run --task-id db-backup --create ./database-backup.sh
```

The --create option is required the first time you run a task.
